## Description

A simple web-based **Grade Calculator** built with HTML, CSS, and JavaScript. This program allows students to input their scores for different assessments (quiz, assignment, midterm, and final exam) and calculates the weighted average along with the corresponding letter grade.

### Features
- Input scores for Quiz, Assignment, Midterm Exam, and Final Exam
- Automatic weighted average calculation
- Letter grade determination (A+ to F)
- Pass/Fail status indicator
- Clean and responsive user interface
- Input validation (scores must be between 0–100)

### Grading Weights
| Assessment     | Weight |
|----------------|--------|
| Quiz           | 20%    |
| Assignment     | 20%    |
| Midterm Exam   | 25%    |
| Final Exam     | 35%    |

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/baldojefferson2-alt/grade-calculator.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd grade-calculator
   ```

3. **Open the application:**
   - Simply open `index.html` in any modern web browser (Chrome, Firefox, Edge, etc.).
   - No server or installation required — it runs entirely in the browser.

4. **Use the calculator:**
   - Enter your name and scores in the input fields.
   - Click **"Calculate Grade"** to see your weighted average, letter grade, and pass/fail status.
